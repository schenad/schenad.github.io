Rachel’s Theme - Memory —《杀戮的天使》

第 5–6 话 BGM · 官方 OST 尚未发布时，从带对白的动画声音里还原配乐
动画Noisycroak杀戮的天使

Bilibili · Rachel’s Theme - Memory · 在 Bilibili 打开

Bilibili · Rachel’s Theme（前一版） · 在 Bilibili 打开

从第 5 话延伸到第 6 话

这段 BGM 出现在《杀戮的天使》第 6 话结尾，是我前一周做的第 5 话结尾 BGM Rachel’s Theme 的延伸版本。两首曲子的开头其实是一样的。

当时官方 OST 还没有发布，所以这两个版本都是根据动画里实际出现的声音一点一点听出来的。

“高仿注意”

我当时把音频做出来以后，自己听着都觉得和动画里的原曲非常接近，甚至忍不住怀疑是不是刚好“撞了音源”233333……不过确实是自己扒的。

真正麻烦的地方在于：动画里出现这段 BGM 的场景都有角色说话，并没有一条干净的音乐轨可以直接听。尤其是结尾，Ray 的“Zack”还循环了很多很多遍 TAT。

所以这个版本不只是“听旋律写音符”，更像是在对白、环境声和效果音下面，一点一点辨认背景音乐的旋律、和声和音色，再把它重新搭出来。
